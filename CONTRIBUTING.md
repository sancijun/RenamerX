# Contributing to the RenamerX public repository

Thank you for helping improve RenamerX's public documentation and examples.

## Repository scope

This repository accepts contributions to:

- public documentation;
- naming-template examples and workflow guidance;
- issue forms and community-support materials;
- corrections to public links and installation instructions.

The RenamerX desktop application is proprietary. Its source code is not published here, and this repository does not accept application-source pull requests.

## Before opening an issue

1. Search existing issues and the [official documentation](https://renamerx.com/docs).
2. Confirm that the problem still occurs in the latest version available through your installation channel.
3. Remove private filenames, paths, document contents, API keys, license keys, and personal information.
4. Use a minimal synthetic file when a reproduction needs sample data.

Security vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md).

## Pull requests

- Keep one focused change per pull request.
- Use concise, factual language and avoid unverified product claims.
- Preserve the distinction between built-in local AI and user-selected local or cloud providers.
- Do not add private source code, internal documents, secrets, binaries, or customer data.
- Update both `README.md` and `README.zh-CN.md` when a shared fact changes.
- Confirm that all Markdown links and relative image paths work.
