# RenamerX support

Choose the channel that matches the request:

| Request | Channel |
| --- | --- |
| Reproducible application bug | [GitHub bug report](https://github.com/sancijun/RenamerX/issues/new?template=bug_report.yml) |
| Focused product suggestion | [GitHub feature request](https://github.com/sancijun/RenamerX/issues/new?template=feature_request.yml) |
| Setup and common problems | [Troubleshooting guide](https://renamerx.com/docs/help-support/troubleshooting) |
| Account, purchase, or license help | [support@renamerx.com](mailto:support@renamerx.com) |
| Security vulnerability | Follow [SECURITY.md](SECURITY.md) |

Before opening a public issue, search existing issues and remove confidential filenames, paths, document contents, API keys, license keys, personal data, and client information. Do not upload real sensitive files or unredacted diagnostic archives.
