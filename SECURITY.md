# Security policy

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected security vulnerability.

Email [support@renamerx.com](mailto:support@renamerx.com) with the subject `Security report: <short summary>` and include:

- the affected RenamerX version and operating system;
- the installation channel;
- a clear description of the issue and its potential impact;
- reproducible steps or a minimal proof of concept;
- any mitigations you have already tried;
- a safe way to contact you for follow-up.

Do not send real customer files, API keys, license keys, authentication tokens, or unredacted diagnostic archives. Use synthetic data whenever possible and agree on a secure transfer method before sending sensitive material.

We will acknowledge a complete report as soon as practical, investigate it, and coordinate remediation and disclosure based on severity and affected users. Please allow reasonable time for a fix before publishing details.

## Supported versions

Security fixes are delivered through currently supported distribution channels. Install the latest version available through the official website, Homebrew Cask, or Microsoft Store before reporting a problem that may already be fixed.

## Scope

Reports about the RenamerX website, desktop application, update flow, licensing flow, or official download infrastructure are in scope. Vulnerabilities in third-party AI providers should be reported to the provider unless the issue is caused by RenamerX's integration.
